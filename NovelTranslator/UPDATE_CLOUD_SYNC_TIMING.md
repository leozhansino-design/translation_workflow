## ✨ 新功能

### 1. ⏰ API 超时时间调整
**问题**: 大文件翻译时，API 请求可能在 30 分钟后超时
**解决方案**:
- ✅ 将 API 超时时间从默认值调整为 **1小时（3600秒）**
- ✅ 使用 `httpx.Client` 和 `httpx.AsyncClient` 设置自定义超时
- ✅ 支持更大文件的翻译任务

**代码位置**:
- `main.py:943-950` (同步API)
- `main.py:991-998` (异步API)

### 2. 📊 改进的翻译状态显示
**问题**: API 返回时间和完成时间差异大，用户不清楚进度
**解决方案**:
- ✅ 收到API返回时立即显示 **"✅ 收到翻译件"** 状态
- ✅ 分别记录 **API时间**、**处理时间**、**总时间**
- ✅ 在日志中详细显示各阶段耗时

**状态流程**:
```
运行中 → ✅ 收到翻译件 (131秒) → 完成 (总计250秒)
```

**时间分解**:
- `api_time`: API调用时间（纯网络+生成时间）
- `processing_time`: 后处理时间（保存文件、提取tags、人名匹配等）
- `time`: 总时间

**代码位置**: `main.py:785-825`

### 3. 📁 打开输出文件夹按钮
**新增功能**:
- ✅ 一键打开翻译结果文件夹
- ✅ 跨平台支持（Windows / macOS / Linux）
- ✅ 自动识别操作系统并使用对应命令

**按钮位置**: 主界面开始翻译按钮旁边

**代码位置**: `main.py:561-590`

### 4. ☁️ 云端数据同步功能 (全新)
**核心功能**: 多台电脑共享配置文件

#### 支持的云存储服务:
- ☁️ **iCloud Drive** (macOS)
- ☁️ **OneDrive** (Windows/Mac)
- ☁️ **Dropbox** (Windows/Mac)
- ☁️ **Google Drive** (Windows/Mac)
- 📂 **自定义路径** (任何云同步文件夹)

#### 可同步的文件:
- ✅ `default_prompt.json` - 翻译Prompt模板
- ✅ `names.json` - 人名库
- ✅ `styles.json` - 写作风格库
- ✅ `summary.json` - 翻译记录

#### 使用方法:

**步骤1: 打开云端同步设置**
- 点击主界面顶部 **"☁️ 云端同步"** 按钮

**步骤2: 配置云端路径**
- 选择云存储服务提供的同步文件夹
- 例如:
  - macOS: `~/Library/Mobile Documents/com~apple~CloudDocs/NovelTranslator`
  - Windows OneDrive: `C:\Users\用户名\OneDrive\NovelTranslator`
  - Dropbox: `C:\Users\用户名\Dropbox\NovelTranslator`

**步骤3: 启用同步**
- ✅ 勾选 "启用云端同步"
- ✅ 选择需要同步的文件
- 💾 点击 "保存"

**步骤4: 迁移数据**
- 首次启用时会提示是否将本地数据迁移到云端
- 已存在的云端文件不会被覆盖
- 其他电脑安装后直接启用云端同步即可

#### 工作原理:
```
电脑1 (Mac)              云端文件夹                 电脑2 (Windows)
    ↓                        ↓                           ↓
本地读写 ←→ iCloud Drive/OneDrive/Dropbox ←→ 本地读写
                             ↓
                    所有电脑共享最新数据
```

**代码位置**:
- `cloud_sync.py` - 云端同步核心模块
- `config.py:19-36` - 配置管理器集成
- `resource_mgr.py:22-33` - 资源管理器集成
- `translator.py:25-34` - 翻译器集成
- `main.py:1361-1594` - UI设置界面

## 📝 配置文件位置

### 本地配置
- **macOS**: `~/Library/Application Support/NovelTranslator/`
- **Windows**: `~/AppData/Local/NovelTranslator/`
- **Linux**: `~/.config/NovelTranslator/`

### 云端同步配置文件
- 位置: `cloud_sync_config.json`
- 内容:
  ```json
  {
    "enabled": true,
    "cloud_type": "onedrive",
    "cloud_path": "C:/Users/xxx/OneDrive/NovelTranslator",
    "sync_items": {
      "defaultprompt": true,
      "names": true,
      "styles": true,
      "summary": true
    }
  }
  ```

## ⚠️ 注意事项

1. **首次设置**: 需要重启应用使云端同步生效
2. **网络要求**: 云存储服务需要正常同步
3. **冲突处理**: 建议同一时间只在一台电脑上修改配置
4. **备份建议**: 定期备份云端文件夹
