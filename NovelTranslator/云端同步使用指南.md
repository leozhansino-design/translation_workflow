# ☁️ 云端同步使用指南

## 🎯 功能说明

云端同步可以让您的**3台电脑**（Windows + 2台Mac）共享以下配置文件：
- 📝 `default_prompt.json` - 翻译Prompt模板
- 👤 `names.json` - 人名库（避免重复使用人名）
- ✍️ `styles.json` - 写作风格库（轮流使用）
- 📊 `summary.json` - 翻译记录汇总

## 🚀 快速设置（3步完成）

### 第1步：选择云存储服务

推荐使用 **OneDrive**（Windows和Mac都支持）

其他选择：
- **iCloud Drive** - 只适合Mac之间同步
- **Dropbox** - 需要单独安装
- **Google Drive** - 需要单独安装

### 第2步：在第一台电脑上设置

#### 1. 创建云端文件夹

**Windows (OneDrive):**
```
路径：C:\Users\你的用户名\OneDrive\NovelTranslator
```

**Mac (OneDrive):**
```
路径：~/OneDrive/NovelTranslator
```

**Mac (iCloud Drive):**
```
路径：~/Library/Mobile Documents/com~apple~CloudDocs/NovelTranslator
```

#### 2. 在应用中设置

1. 打开小说翻译工具
2. 点击顶部 **"☁️ 云端同步"** 按钮
3. 在弹出的设置窗口中：

   ![云端同步设置窗口]

   - ✅ **勾选** "启用云端同步"
   - 📁 **输入路径**（或点击"浏览"选择文件夹）
     - Windows: `C:\Users\你的用户名\OneDrive\NovelTranslator`
     - Mac OneDrive: `/Users/你的用户名/OneDrive/NovelTranslator`
     - Mac iCloud: `/Users/你的用户名/Library/Mobile Documents/com~apple~CloudDocs/NovelTranslator`

   - ✅ **选择同步项目**（默认全选）：
     - ✅ Default Prompt
     - ✅ 人名库 (names.json)
     - ✅ 风格库 (styles.json)
     - ✅ 翻译记录 (summary.json)

   - 🧪 **点击"测试路径"** 确认路径可用

   - 💾 **点击"保存"**

#### 3. 迁移本地数据

保存后会提示：

```
是否将本地配置文件复制到云端？
（已存在的云端文件不会被覆盖）
```

- ✅ **点击"是"** - 将现有的配置文件复制到云端

#### 4. 重启应用

设置完成后，**重启应用**使配置生效。

### 第3步：在其他电脑上设置

#### 1. 等待云同步完成

确保OneDrive/iCloud已经将文件同步到其他电脑。

检查文件夹是否存在：
```
OneDrive/NovelTranslator/data/
├── default_prompt.json
├── names.json
├── styles.json
└── summary.json
```

#### 2. 在第二台、第三台电脑上

1. 打开小说翻译工具
2. 点击 **"☁️ 云端同步"** 按钮
3. **输入相同的云端路径**
4. ✅ 勾选"启用云端同步"
5. **不需要**迁移数据（因为云端已有数据）
6. 💾 点击"保存"
7. 重启应用

## ✅ 验证设置是否成功

### 方法1: 查看日志
在应用底部的日志区域查看：
```
[INFO] 配置文件路径: /Users/xxx/OneDrive/NovelTranslator/data/names.json
```

如果看到云端路径，说明设置成功！

### 方法2: 测试修改
1. 在第一台电脑修改Prompt
   - 点击 "📝 编辑Default Prompt"
   - 修改内容并保存
2. 等待云同步（通常几秒钟）
3. 在第二台电脑重启应用
4. 检查Prompt是否已更新

## 🔧 常见问题

### Q1: 路径不对怎么办？

**A:** 点击"浏览"按钮，手动选择文件夹：

**Windows推荐路径:**
```
C:\Users\你的用户名\OneDrive\NovelTranslator
```

**Mac推荐路径:**
```
OneDrive: /Users/你的用户名/OneDrive/NovelTranslator
iCloud: /Users/你的用户名/Library/Mobile Documents/com~apple~CloudDocs/NovelTranslator
```

### Q2: 测试路径提示"路径不存在"？

**A:** 手动创建文件夹：

**Windows:**
1. 打开文件资源管理器
2. 进入 `C:\Users\你的用户名\OneDrive\`
3. 右键 → 新建文件夹 → 命名为 `NovelTranslator`

**Mac:**
1. 打开Finder
2. 前往 → 前往文件夹 → 输入 `~/OneDrive/`
3. 新建文件夹 → 命名为 `NovelTranslator`

### Q3: 云端文件没有同步？

**A:** 检查云存储服务状态：

**OneDrive:**
- Windows: 右下角托盘查看OneDrive图标
- Mac: 顶部菜单栏查看OneDrive图标
- 确保显示"已同步"状态

**iCloud:**
- Mac: 系统设置 → Apple ID → iCloud → iCloud Drive
- 确保已启用并同步完成

### Q4: 多台电脑同时修改会冲突吗？

**A:** 建议避免同时修改：
- ✅ **推荐**: 在一台电脑上修改配置，等云同步完成后，其他电脑重启应用
- ❌ **避免**: 同时在多台电脑上修改Prompt或配置

如果发生冲突，OneDrive/iCloud会创建冲突副本，手动合并即可。

### Q5: 可以中途禁用云端同步吗？

**A:** 可以！
1. 打开"☁️ 云端同步"设置
2. 取消勾选"启用云端同步"
3. 保存并重启应用
4. 应用会回到使用本地配置文件

### Q6: 翻译结果文件会同步吗？

**A:** **不会！**
- 只同步配置文件（names.json, styles.json, prompt, summary）
- 翻译结果保存在本地 `output/` 文件夹
- 如需备份翻译结果，请手动复制 `output/` 文件夹

## 📊 推荐的工作流程

### 方案1: 集中式（推荐）

```
主电脑（Mac） - 管理配置
    ↓
修改Prompt、添加人名、调整风格
    ↓
自动同步到云端
    ↓
其他电脑 - 只翻译
    ↓
使用云端的配置文件
自动记录到云端summary.json
```

### 方案2: 分布式

```
3台电脑都可以修改配置
    ↓
修改前确保其他电脑没在使用
    ↓
修改后等待云同步
    ↓
其他电脑重启应用获取最新配置
```

## 🎁 额外功能

### 自动备份

云端文件夹本身就是备份！
- OneDrive有版本历史（30天）
- iCloud有版本历史
- 误删除可以恢复

### 导出配置

云端文件夹路径：
```
NovelTranslator/
├── data/
│   ├── default_prompt.json  ← 可以直接编辑
│   ├── names.json            ← 可以直接编辑
│   ├── styles.json           ← 可以直接编辑
│   └── summary.json          ← 查看所有翻译记录
└── README.txt
```

你可以：
- 直接用文本编辑器打开修改
- 复制到其他项目使用
- 分享给他人
